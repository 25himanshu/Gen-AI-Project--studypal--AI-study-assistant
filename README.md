# 🎓 StudyPal – AI Study Assistant

### Learn Smarter. Understand Better. Study Faster.

StudyPal is a Generative AI-powered study assistant designed specifically for **Class 12 students**. It makes learning more interactive and efficient by allowing students to ask questions about their study materials, understand complex concepts, and receive relevant, context-aware answers using modern AI technologies.

## 🚀 Key Features

- **AI-Powered Q&A:** Helps Class 12 students ask questions and get intelligent responses.
- **Context-Aware Answers:** Retrieves relevant information from Class 12 study materials.
- **Smart Learning:** Explains complex topics in a simple and understandable way.
- **Interactive Interface:** User-friendly experience built with Streamlit.
- **Document-Based Learning:** Uses Retrieval-Augmented Generation (RAG) to provide relevant answers from educational content.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **AI & LLM:** Generative AI, Large Language Models (LLMs)
- **Framework:** LangChain
- **Retrieval:** Retrieval-Augmented Generation (RAG)
- **Vector Database:** FAISS
- **Frontend:** Streamlit

## ⚙️ How It Works

1. Class 12 study materials are provided to the application.
2. The content is processed and converted into searchable vector embeddings.
3. FAISS retrieves relevant information based on students' questions.
4. LangChain connects the retrieval process with the language model.
5. The AI generates context-aware answers to help students understand their subjects.

## 💻 Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/25himanshu/StudyPal-AI-Assistant.git
```

**2. Navigate to the project folder**

```bash
cd StudyPal-AI-Assistant
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```

## 🎯 Project Objective

To create an AI-powered learning companion specifically for Class 12 students that simplifies complex topics, provides quick answers from study materials, and makes exam preparation more personalized, accessible, and effective.
